# Christmas Lights Snake Game

A festive Christmas-themed single-player Snake game built with HTML, CSS, and JavaScript. Guide your string of Christmas lights to collect presents!

## Features

- Christmas-themed gameplay with holiday visuals
- Animated falling snowflakes background
- Snake transformed into colorful Christmas lights (red, green, gold)
- Collect Christmas presents instead of food
- Score tracking with persistent high score (saved in browser)
- Progressive difficulty - game speeds up as you collect more presents
- Beautiful Christmas color scheme (red, green, gold)
- Night sky background with animated snowfall
- Glowing light bulb effects with gradient colors
- Festive UI with holiday emojis

## How to Play

1. Open `index.html` in any modern web browser
2. Click "Start Game" to begin
3. Use the arrow keys to control your Christmas lights:
   - ↑ Up Arrow - Move up
   - ↓ Down Arrow - Move down
   - ← Left Arrow - Move left
   - → Right Arrow - Move right
4. Collect Christmas presents to grow your light string
5. Avoid hitting the walls or yourself
6. Enjoy the festive snowfall!

## Game Rules

- Each present collected gives you 1 point
- Your Christmas light string grows longer with each present
- Game speed increases every 5 presents collected
- Game ends if you hit a wall or your own lights
- High score is saved locally in your browser
- The lights alternate between festive colors: red, green, gold, pink, and cyan

## Technical Details

- Pure vanilla JavaScript (no frameworks required)
- Canvas-based rendering for smooth graphics
- LocalStorage for high score persistence
- Fully self-contained single HTML file
